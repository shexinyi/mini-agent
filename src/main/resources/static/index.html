一轮请求里循环在做什么

  1. 你的话被追加进 memory。
  2. memory 和工具的 JSON Schema 一起发给模型。
  3. 模型返回 tool_calls 时，执行工具，把结果以 role=tool 追加回 memory，然后回到第 2 步。
  4. 模型只返回文字，或达到 maxSteps，循环结束。
